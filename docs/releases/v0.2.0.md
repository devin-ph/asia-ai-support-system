This page is an evidence index for the contract in
[`docs/demo-scope.md`](../demo-scope.md). It does not redefine scope or release
thresholds.

## Candidate status

**Blocked as of 2026-07-24.** Offline code, regression, evaluation, security,
and E2E gates have executable coverage, but no curated
`eval/results/v0.2-reference.json` exists yet. The genuine pinned-model run and
complete 21-case human review must happen before the release-evidence sub-gate can pass.
No `v0.2.0` tag should be created while this status remains blocked.

Run the final local sequence only after curation and integration onto `main`:

```bash
python scripts/dev.py doctor
python scripts/dev.py verify --release
npm run e2e --prefix frontend
```

`verify --release` is the release-evidence sub-gate. It includes the locked
dependency audit, both evaluation suites, a Git-tracked curated reference, and
clean-`main` requirements. It does not include `doctor` or E2E; both are
separate commands above. CI uses no external-provider credential and makes no
generator API call; its setup still downloads dependencies and Playwright
Chromium.
